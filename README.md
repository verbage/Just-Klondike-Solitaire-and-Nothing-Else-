# Just-Klondike-Solitaire-and-Nothing-Else
A Klondike Solitare game provided as a single, ~35KB, self-contained HTML/JavaScript file.  No bloat, no ads, no phone home or need to be online, no invasive permissions, nothing--just what is needed for the game itself.

There is no need to formally install this file--just send the single HTML/JavaScript file over to your phone or tablet and run it in your local browser.  If you want, you can use Chrome's "Add to Home screen" functionality to make it appear and behave like an app.

Note:  you do need to have JavaScript enabled for this to work!

I do not have an Apple iOS device to test this on, but as it is a simple HTML/JavaScript file, I expect it should work.

# Background

I've never really played games on my phone or tablet, but recently, I decided to load up a simple Klondike Solitaire game before a long trip to help pass the hours.  When I visited the Google Play store, I found a gazillion variants--great!  But every single one was either paid or freemium style and filled with ads, or needed to know my location, or needed to communicate over the Internet, or was simply grossly bloated, or involved some ensh*ttified combination of the above.  Disgusting.

So with all the reverse engineering going on, I decided to ask Claude for some help with producing a simple Android app without all the bloat, invasive permissions, etc.  My first thought was a simple APK that one could sideload.  But Claude suggested a single, self-contained HTML/JavaScript file, so we went with that.  And honestly, it makes great sense because you can literally read through the file yourself and verify that it contains nothing more than is needed for the game itself.  And furthermore, it is not tied to just Android--it should work for any device that can render HMTL/JavaScript.

This work is 100% Claude--I just provided detailed and explicit guidance about what I wanted, and Claude did the rest.  I have only demo'ed this briefly, but I'm sure there will be bugs, which I will fix.
